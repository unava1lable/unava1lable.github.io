# 内存模型基础
## 改动序列
每个C++对象都具有一个改动序列，它由所有线程在对象上的全部写操作构成，其中第一个写操作是对象的初始化。大部分情况下，这个序列会随程序的多次运行而发生变化，但是在程序的某一次运行种，所含全部线程必须形成相同的改动序列。

## C++中的原子操作及其类别
原子操作是不可分割的操作：要么完全做好，要么完全没做。多数情况下，我们需要通过原子类型实现原子操作。
### 标准原子类型
每个`std::atomic`模板的实例化和全特化均定义一个原子类型。如果一个线程写入原子对象，同时另一线程从它读取，那么行为有良好定义。

主`std::atomic`模板可用任何满足可复制构造及可复制赋值的可平凡复制类型`T`实例化。

标准库为下列类型提供`std::atomic`模板的特化，它们拥有主模板所不拥有的额外属性：
* 针对所有指针类型的部分特化`std::atomic<U*>`。这些特化拥有标准布局、平凡默认构造函数和平凡析构函数。除了为所有原子类型提供的操作外，这些特化额外支持适合指针类型的原子算术运算，例如`fetch_add`、`fetch_sub`。
* 针对`std::shared_ptr`和`std::weak_ptr`提供的部分特化 `std::atomic<std::shared_ptr<U>>`和`std::atomic<std::weak_ptr<U>>`。

以下列整数类型之一实例化时，`std::atomic`提供适合于整数类型的额外原子操作，例如`fetch_add`、`fetch_sub`、`fetch_and`、`fetch_or`、`fetch_xor`：
* 字符类`char`等
* 标准有符号整型`int`等
* 标准无符号整型`unsigned int`等

## 同步操作和强制次序
有两个线程同时操作一个数据结构，一个负责添加，一个负责读取。为避免恶性条件竞争，设置一个标志位表明数据以存储妥当。
```cpp
#include <vector>
#include <iostream>
#include <atomic>
#include <thread>
#include <chrono>

std::vector<int> data{};
std::atomic<bool> ready{false};

void reader() {
    while (!ready.load()) {
        std::this_thread::sleep_for(std::chrono::milliseconds(1));
    }
    std::cout << "The answer is " << data[0] << std::endl;
}

void writer() {
    data.push_back(10);
    ready.store(true);
}

int main() {
    for (int i = 0; i < 10; i++) {
        std::thread t1(reader);
        std::thread t2(writer);
        t1.join();
        t2.join();
    }
    return 0;
}
```

线程间同步和内存定序决定了表达式的求值和副作用如何在不同的执行线程间排序:
* 同步关系：如果在线程A上的一个原子store是release操作，在线程B上的对相同变量的一个原子load是acquire操作，且线程B上的load由线程A上的store的值，则线程A上的store同步于线程B上的load。
